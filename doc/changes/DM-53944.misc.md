Changes made to support multiple ``BPS`` config yaml files needing to add to the same path for a job, for example to separately add caching and compression paths to ``DAF_BUTLER_CONFIG_PATH``.  Previously, when including a config, the 2nd value for a key would just replace the 1st value.  Now if a key ends in ``_PATH`` and the value contains ``${key}`` and there was a previous value for key, the old value will replace ``${key}`` in the new value.  This new config behavior mimics shell behavior as shown by these shell commands ``A_PATH="/some/path1";A_PATH="/some/path2:${A_PATH}"; echo ${A_PATH}`` prints ``/some/path2;/some/path1)``.
